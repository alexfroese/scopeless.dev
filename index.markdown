# Coding is easy. Coding well is hard

I'm just starting out with blogging, I never quite felt a draw until recently, so if this adventure
pans out, cool. I just hope to start some conversations about development. That'll be easier if I
figure out how to have comments or something on here. Bear with me, I'm new to this, and just
figuring out how much work I want to put into this. It's just Jekyll for now, but who knows what
this could turn into.

Maybe none of my thoughts are original, but when has that ever stopped a creative endeavor?

As the name sort of implies, I don't really know how much I'll cover. There will be some code talk,
some talk about working in teams, maybe some talk about solo work. I'll do my best to keep things
pretty anonymous so if this gets back to somebody who knows me, I'm not calling anyone out
specifically. And if any of this sounds familiar to anyone, I'm not here to shame anyone either, I
really just want everybody to get better. But if you do feel shame, maybe that's a hint that
there's a thing or two you need to work on.
